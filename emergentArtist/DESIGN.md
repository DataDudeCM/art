# Emergent Artist — Design & Architecture

## 1. Purpose

**Emergent Artist** is an experimental generative-art system in which autonomous visual agents move through a shared canvas, perceive their environment, and decide when and how to leave marks.

Rather than directly constructing a composition, the system creates conditions from which a composition can emerge.

A higher-level **Artist Agent** periodically observes the evolving artwork and influences the environment, agent population, and behavioral pressures. It does not normally place individual marks itself.

The central feedback loop is:

**Emergence → Observation → Influence → New Emergence**

The goal is not to encode a recipe for making attractive abstract artwork. The goal is to explore whether a population of relatively simple visual agents, operating under changing artistic pressures, can collectively produce compositions that feel intentional without those compositions being explicitly designed in advance.

---

# 2. Relationship to Existing Projects

Emergent Artist is conceptually descended from **Abstract Artist**, but should be developed as a separate project.

Abstract Artist provides useful foundations and lessons involving:

- palettes
- canvas management
- paper and surface textures
- watercolor rendering
- ink rendering
- geometric elements
- compositional analysis
- artistic intent
- controlled randomness
- visual relationships

Those capabilities should be reused or adapted where appropriate.

However, the fundamental architecture is different.

### Abstract Artist

```text
Artistic Intent
      ↓
Composition Rules
      ↓
Rendering System
      ↓
Artwork
```

### Emergent Artist

```text
Artist Agent
      ↓
Environmental Influence
      ↓
Autonomous Element Agents
      ↓
Artwork
      ↓
Observation
      ↺
```

The composition is therefore not directly generated by the Artist Agent.

It emerges from the behavior of the entire system.

---

# 3. Relationship to the Diamond Age Artistic Agent Studio

Emergent Artist should remain independent from the Diamond Age Artistic Agent Studio.

The two projects explore related ideas at different levels.

### Diamond Age

Agents behave like:

- artists
- critics
- collaborators
- researchers
- creative personalities

### Emergent Artist

Agents behave more like:

- marks
- materials
- visual gestures
- shapes
- drawing behaviors

A future Diamond Age artist could potentially use Emergent Artist as one of its creative tools, but the projects should not initially share architecture.

---

# 4. Core Design Principles

## 4.1 Emergence Over Prescription

No component should have complete knowledge of the desired final composition.

Interesting visual structure should arise from interactions between:

- autonomous agents
- local perception
- personality
- environmental fields
- population dynamics
- artistic influence
- randomness

Whenever possible, prefer:

> Create a condition that encourages something to happen.

over:

> Explicitly make that thing happen.

---

## 4.2 Artist as Influencer, Not Illustrator

The Artist Agent should generally not issue commands such as:

```text
Draw a large red circle at (430, 210).
```

Instead it should influence conditions:

```text
Increase visual activity in the lower-right.

Reduce circle dominance.

Encourage stronger directional gestures.

Protect this region of negative space.
```

Element agents determine how those pressures become actual marks.

---

## 4.3 Simple Agents, Complex System

Individual agents should remain understandable.

Complexity should primarily emerge from interactions among:

- agents
- personalities
- fields
- history
- composition
- Artist Agent intervention

Avoid putting sophisticated global composition logic inside every element agent.

---

## 4.4 Species, Personality, and State Are Separate

Every visual agent has three distinct concepts.

### Species

Defines its fundamental visual vocabulary.

Examples:

```text
Circle
Line
Triangle
Square
Arc
Text
Doodle
```

### Personality

Defines relatively persistent individual traits.

Example:

```text
large
delicate
slow
curious
social
low repetition
high roughness
```

### State

Defines temporary conditions.

Example:

```text
position
velocity
energy
age
local density
nearby agents
current field strength
recent drawing history
```

These concepts must remain architecturally separate.

# 6. Element Agents

All visual agents derive from a common `BaseAgent`.

Possible species include:

```text
CircleAgent
LineAgent
TriangleAgent
SquareAgent
ArcAgent
TextAgent
DoodleAgent
```

Additional species can be introduced without changing the overall simulation architecture.

Each agent:

1. moves
2. senses its surroundings
3. reads influence fields
4. evaluates its internal state
5. decides whether to draw
6. determines the characteristics of the mark
7. asks a renderer to create the mark
8. updates its state

---

# 7. Agent Personality

Agents of the same species should be capable of behaving radically differently.

A CircleAgent is therefore not simply "something that draws circles."

It is an autonomous entity whose visual vocabulary happens to be circular.

Possible personality traits include:

## Movement

```text
speed
wander
inertia
curiosity
directional persistence
attraction sensitivity
repulsion sensitivity
```

## Mark Characteristics

```text
preferred scale
scale variation
opacity
weight
roughness
completeness
distortion
fill probability
mark complexity
```

## Behavioral Characteristics

```text
drawing frequency
persistence
repetition
sociability
avoidance
curiosity
risk
territoriality
responsiveness
```

## Tool Preferences

```text
brush preference
ink preference
watercolor preference
pencil preference
tool consistency
tool experimentation
```

Personality traits should generally be normalized values where practical, allowing interpolation, mutation, and inheritance.

---

# 8. Example Agent Personalities

Two CircleAgents might have identical species but dramatically different personalities.

### Agent A

```text
species: Circle

scale: large
opacity: low
movement: slow
roughness: high
drawing frequency: low
curiosity: medium
sociability: low
tool: watercolor
```

Result:

> Large, pale, hesitant watercolor circles.

### Agent B

```text
species: Circle

scale: small
opacity: high
movement: fast
roughness: medium
drawing frequency: high
repetition: high
tool: ink
```

Result:

> Small, aggressive, repeated dark rings.

The visual language comes from the interaction between **species + personality + state + environment + renderer**.

# 9. Agent State

Personality represents who the agent generally is.

State represents what is happening to it now.

Possible state:

```text
position
velocity
age
energy
recent marks
distance traveled
time since last mark
nearby agent count
nearby species
local density
local field values
recent interactions
```

Future state concepts could include:

```text
fatigue
confidence
frustration
stimulation
memory
territory
```

These should only be introduced when they create meaningful visual behavior.

---

# 10. Perception

Agents should have limited local perception.

They should not normally understand the entire composition.

An agent may perceive:

```text
nearby agents
nearby marks
local canvas density
local color
distance from canvas edges
local influence fields
recent activity
```

Different personalities may respond differently to identical perceptions.

For example:

```text
high-sociability agent
    → moves toward nearby agents

low-sociability agent
    → moves away

curious agent
    → investigates unusual regions

territorial agent
    → remains near previous marks
```

---

# 11. Influence Fields

Influence fields provide the primary communication mechanism between global artistic intent and local autonomous behavior.

Fields are invisible spatial maps over the canvas.

Initial candidates include:

## Interest Field

Indicates areas where increased activity may be desirable.

## Repulsion Field

Discourages agents from entering or drawing within particular regions.

Useful for preserving negative space.

## Attraction Field

Pulls agents toward selected regions.

## Density Field

Represents existing visual activity.

Agents may independently prefer or avoid dense regions.

## Direction Field

Encourages movement or marks along particular directional flows.

## Scale Field

Influences mark size spatially.

## Drawing Probability Field

Modifies the likelihood that agents will leave marks.

Fields should generally influence behavior rather than dictate it.

An agent may ignore, resist, amplify, or respond weakly to a field depending upon its personality.

---

# 12. Renderers

Agent intelligence and mark rendering should remain separate.

An agent decides **what kind of mark it wants to make**.

A renderer decides **how that mark physically appears**.

Possible renderers:

```text
InkRenderer
BrushRenderer
WatercolorRenderer
PencilRenderer
MarkerRenderer
VectorRenderer
```

An agent might generate a mark request resembling:

```text
shape: circle
position: ...
scale: ...
weight: ...
opacity: ...
roughness: ...
completion: ...
rotation: ...
```

The selected renderer interprets those characteristics.

This allows the same agent behavior to produce very different artwork.

A TriangleAgent could use:

```text
watercolor
ink
dry brush
pencil
```

without requiring separate triangle behavior implementations.

---

# 13. Composition Analyzer

The Artist Agent requires measurable information about the evolving canvas.

A dedicated `CompositionAnalyzer` should calculate useful visual statistics.

Initial measurements could include:

```text
regional density
center of visual mass
negative-space distribution
element frequency
species distribution
mark scale distribution
dominant orientation
color distribution
edge activity
clustering
repetition
contrast
```

Later analysis may include:

```text
focal-point detection
visual flow
balance
rhythm
tension
hierarchy
novelty
stagnation
```

The analyzer should report observations rather than make artistic decisions.

---

# 14. Artist Agent

The Artist Agent periodically evaluates the composition.

It operates on a much slower timescale than element agents.

For example:

```text
Element Agents:
evaluate every frame

Artist Agent:
evaluate every 100–500 frames
```

The exact interval should be configurable.

The Artist may decide that:

```text
upper-left is becoming too dense
lower-right is inactive
circles dominate excessively
mark scale lacks variation
directionality is weak
composition is becoming repetitive
```

It then changes pressures rather than directly repairing the artwork.

Possible interventions:

```text
modify influence fields
change drawing probabilities
change species populations
modify personality distributions
encourage or suppress reproduction
remove agents
introduce agents
alter environmental parameters
```

---

# 15. Artist Personality

The Artist Agent itself should eventually have personality.

Possible dimensions:

```text
order        ←────────→ chaos
minimalism   ←────────→ density
harmony      ←────────→ tension
repetition   ←────────→ variation
geometry     ←────────→ gesture
stability    ←────────→ mutation
control      ←────────→ observation
```

Artist presets might include:

### Quiet Minimalist

Protects negative space, reduces repetition, and intervenes strongly against overcrowding.

### Restless Constructivist

Encourages intersections, diagonals, structural relationships, and visual tension.

### Chaotic Doodler

Rewards unusual relationships and tolerates substantial disorder.

### Curious Observer

Interferes minimally and primarily reacts to stagnation.

The **Curious Observer** should be an important early personality because it provides the strongest test of genuine emergence.

---

# 16. Population Dynamics

Agent populations should be dynamic.

The Artist Agent may influence:

```text
birth
death
reproduction
mutation
population limits
species ratios
```

A species may potentially disappear entirely during a composition.

For example:

```text
CircleAgents:   14 → 8 → 3 → 0
LineAgents:      3 → 5 → 9 → 12
TriangleAgents:  2 → 2 → 4 → 3
```

Zero agents of a species is always valid.

No element type is required to appear in the final artwork.

---

# 17. Mutation and Visual Evolution

Personality traits should eventually support mutation.

For example, if the Artist determines that circles are useful but visually overpowering, it might encourage traits such as:

```text
lower opacity
smaller scale
lower drawing frequency
higher roughness
greater incompleteness
```

Rather than explicitly changing every CircleAgent, the system could preferentially retain or reproduce individuals possessing those traits.

Over time the population might evolve toward a visual behavior that better fits the current composition.

This creates the possibility of **visual natural selection**.

The system did not explicitly decide:

> Draw large pale circles.

Instead, those agents survived because their behavior contributed positively to the evolving artwork.

---

# 18. Lifecycle

A simulation might follow this general cycle.

## Initialization

1. Choose palette.
2. Choose Artist personality.
3. Create initial influence fields.
4. Generate initial agent populations.
5. Randomize agent personalities within constraints.

## Continuous Agent Simulation

Every frame:

```text
sense
move
evaluate
possibly draw
update state
```

## Artist Evaluation

Periodically:

```text
analyze canvas
identify tendencies
compare tendencies with Artist personality
modify environmental pressures
possibly alter populations
```

## Continue

The system returns to autonomous simulation.

---

# 19. Stopping Conditions

An artwork should not necessarily run forever.

Possible stopping mechanisms:

```text
maximum frame count
maximum mark count
composition stability
low novelty
agent extinction
Artist satisfaction threshold
manual stop
```

Eventually the Artist might determine:

> Stop touching it.

That decision itself could become part of the artistic behavior.

---

# 20. Explainability and Visualization

Because Emergent Artist is an experimental system, internal behavior should be observable.

Debug modes should eventually allow visualization of:

```text
agent positions
agent species
agent personalities
agent perception radius
velocity
influence fields
density maps
Artist evaluations
birth/death events
drawing decisions
```

This is important both for development and for understanding surprising emergent behavior.

A system that produces an interesting result should make it possible to investigate **why** that result happened.

---

# 21. Reproducibility

Randomness should be seedable.

A seed should ideally reproduce:

```text
initial population
agent personalities
initial positions
field configuration
random decisions
```

This allows interesting behaviors to be studied and modified.

Eventually it may be useful to distinguish between:

```text
environment seed
population seed
behavior seed
rendering seed
```

but a single global seed is sufficient initially.

---

# 22. LLM Integration

The initial Artist Agent should **not** depend upon an LLM.

Early Artist behavior should use:

```text
composition statistics
rules
weighted decisions
heuristics
state machines
probabilistic behavior
```

Advantages include:

```text
speed
debuggability
continuous operation
reproducibility
low computational overhead
```

LLM integration may be explored later as a higher-level **Creative Director**.

Possible future architecture:

```text
Creative Director
       ↓
Artist Agent
       ↓
Influence Fields
       ↓
Element Agents
       ↓
Renderers
       ↓
Canvas
```

The Creative Director would operate infrequently and provide broad conceptual guidance rather than individual drawing instructions.

Example:

> Preserve the quiet lower region but encourage one dominant directional gesture.

The Artist Agent would translate that instruction into numerical pressures.

# 24. Development Strategy

The project should be built incrementally.

Do **not** begin with every envisioned feature.

## Phase 1 — Autonomous Marks

Implement:

```text
BaseAgent
CircleAgent
LineAgent
basic personality
simple movement
simple renderer
seeded randomness
```

Goal:

Agents move independently and produce visibly different marks according to personality.

No Artist Agent yet.

---

## Phase 2 — Local Perception

Add:

```text
nearby-agent sensing
density awareness
basic attraction
basic avoidance
```

Goal:

Agent behavior begins responding to the evolving environment.

---

## Phase 3 — Influence Fields

Add:

```text
InterestField
RepulsionField
DensityField
```

Goal:

External pressures influence agents without directly controlling them.

---

## Phase 4 — Composition Analyzer

Measure:

```text
regional density
negative space
center of mass
species distribution
scale distribution
```

Goal:

The system can describe important properties of its own composition.

---

## Phase 5 — Artist Agent

Introduce the first Artist Agent.

It may initially manipulate only:

```text
population
drawing probability
scale pressure
attraction/repulsion
```

Goal:

Determine whether slow feedback from the Artist produces meaningfully better or more interesting emergent compositions.

---

## Phase 6 — Personality Evolution

Introduce:

```text
agent birth
agent death
trait mutation
selection pressure
```

Goal:

Allow the population's visual behavior to evolve during a composition.

---

## Phase 7 — Expanded Visual Vocabulary

Only after the underlying system proves interesting, add:

```text
TriangleAgent
SquareAgent
ArcAgent
TextAgent
DoodleAgent

additional renderers
additional fields
additional Artist personalities
```

---

# 25. Initial Experiment

The first meaningful experiment should intentionally be small.

Use only:

```text
CircleAgent
LineAgent
ArtistAgent
```

The Artist initially observes:

```text
regional density
negative space
repetition
visual center of mass
```

The Artist may influence:

```text
agent population
drawing probability
scale
attraction
repulsion
```

The first research question is **not**:

> Does it make beautiful artwork?

The first question is:

> Can the system begin making compositional decisions that were not explicitly programmed?

If the answer begins to become yes, the architecture is producing something worth developing.

---

# 26. What This Project Is Not

Emergent Artist should not become:

- a random shape generator
- a collection of unrelated visual effects
- a traditional procedural composition engine disguised as agents
- an LLM repeatedly deciding where to draw shapes
- a system optimized primarily for polished output
- another mode inside Abstract Artist

The experiment is about the behavior of the system itself.

Interesting artwork is evidence that the system is working.

Possible future experiments include:

- inherited personality traits
- mutation
- competing species
- cooperative agents
- territorial behavior
- memory
- agent fatigue
- mark avoidance
- mark reinforcement
- environmental seasons
- resource-like drawing budgets
- competing Artist Agents
- critic agents
- agent communication
- evolving tool preferences
- learned Artist preferences
- human intervention during evolution
- saving successful populations
- breeding populations from previous artworks
- replaying an artwork's evolutionary history

- animation

These are possibilities rather than commitments.

They should only be introduced when they deepen the central experiment.

---

# 28. Guiding Question

When considering a new feature, ask:

> **Does this feature create richer conditions for emergence, or does it simply give us more direct control over the picture?**

Prefer the former.

The defining idea behind Emergent Artist is:

> **Don't program the composition. Build a world in which the composition can discover itself.**
